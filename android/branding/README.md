# Indoone Android Branding

Canonical Android branding assets mirrored from the main reference.

- `app-icon/source/` — canonical launcher icon vector sources.
- `splash/source/` — canonical splash screen vector sources.
- Android runtime resources live under `android/src/main/res/` because Android loads resources from the Gradle resource source set.

Do not redesign or recolor these assets without an explicit branding change.
